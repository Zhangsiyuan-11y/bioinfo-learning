# bioinfo-learning

张偲源的生物信息学自学仓库。

## 用途

- 记录生物信息学学习路线的每一步产出（notebook、脚本、笔记）
- 作为大三联系导师、考研复试时的公开作品集
- 每完成一个阶段，对应目录下应有可运行的代码和说明

## 目录结构

```
bioinfo-learning/
├── notes/         # 学习笔记（组学格式、统计概念、踩坑记录）
├── notebooks/     # Jupyter/R Markdown 分析报告
└── README.md      # 本文件
```

## 学习路线（2026-10 起）

- 阶段 1：统计学基础 + Python 数据处理（2026 秋）
- 阶段 2：R 语言 + 组学格式认知（2026 冬）
- 阶段 3：完整 RNA-seq 流程复现（2027 春–夏）
- 阶段 4：进实验室，对接考研方向（2027）

## 环境

- 运行环境：WSL2 Ubuntu
- Python 科学栈：numpy / pandas / matplotlib / jupyter
- R：tidyverse / Bioconductor
